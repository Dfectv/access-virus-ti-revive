TI Revive Virus Control - Windows test build
=======================================

INTERNAL TEST BUILD. Not for distribution.

What is in here
- VirusTINative.vst3        the native plug-in, shown as "TI Revive Virus Control" (vendor "TI Revive")
- VirusTINative_ASIO.dll    ASIO driver "TI Revive Virus Audio": the Virus as a sound card
- install.cmd / uninstall.cmd, collect-logs.cmd
- timing-16ths-120bpm.mid   timing test: 256 sixteenth notes at 120 BPM

Requirements
1. Access "Virus TI" software installed (the plug-in loads graphics and firmware from it).
2. TI Revive 0.7.4 installed (USB driver + broker). The Virus must work with TI Revive first.
3. Close any DAW before installing.

Install
1. Unzip this folder anywhere.
2. Double-click install.cmd and allow the admin prompt. Read the window for warnings, then close it.
3. Start the DAW and rescan plug-ins.

Tests (one at a time; note the results)
A. Plug-in: load "TI Revive Virus Control" on a MIDI track. Wait for the bank sync to finish. Play notes,
   turn knobs, switch pages, browse patches, save and reopen the project.
B. Timing: put timing-16ths-120bpm.mid on that track at bar 1, record the plug-in's audio onto an
   audio track (or export/render the song) and keep the WAV.
C. ASIO: in the DAW's audio settings choose the ASIO device "TI Revive Virus Audio", buffer 256.
   - play an audio file from the DAW: it must come out of the Virus' outputs, clean, no crackle
   - record the Virus (inputs "USB 1 L/R") onto an audio track
   - optional: plug-in and ASIO at the same time
D. If anything goes wrong: double-click collect-logs.cmd; it puts a zip of the logs on the desktop.

Uninstall: uninstall.cmd (also copied to C:\Program Files\virus-ti-native). TI Revive is not touched.
